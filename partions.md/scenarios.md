# 🐧 Linux Disk Partitioning & Mounting Practice Scenario

یک سناریوی عملی و گام‌به‌گام برای تمرین پارتیشن‌بندی، ایجاد سیستم‌فایل (File System) و متصل کردن (Mount) دیسک جدید در لینوکس به همراه روش پاکسازی (Cleanup).

---

## 📌 هدف سناریو (Scenario Objective)
هدف این سناریو، مدیریت یک دیسک سخت جدید در لینوکس، پارتیشن‌بندی آن با ابزار `fdisk`، فرمت کردن با سیستم‌فایل `ext4` و اتصال موقت آن به سیستم‌عامل بدون آسیب زدن به دیسک اصلی است.

---

## 🛠️ پیش‌نیازها (Prerequisites)
- یک ماشین مجازی لینوکس (Ubuntu / Debian / CentOS / RHEL)
- دسترسی به کاربر دارای دسترسی `sudo`
- اضافه کردن یک هارد مجازی خام جدید (مثلاً ۲۰ گیگابایت) به ماشین مجازی

---

## 🚀 مراحل اجرا (Step-by-Step Guide)

### 1️⃣ شناسایی دیسک خام (Identify the New Disk)
ابتدا لیست دیسک‌های متصل به سیستم را بررسی کنید تا نام دیسک خام جدید را پیدا کنید:

```bash
lsblk
```
**نکته: مطمئن شو قبل از اجرای دستور بالا در پوشه روت / باشی** 

**نکته: دیسک اصلی سیستم معمولاً sda و دیسک جدید معمولاً sdb نام دارد.**

### 2️⃣ پارتیشن‌بندی دیسک (Disk Partitioning)

ورود به ابزار مدیریت دیسک برای sdb:

``sudo fdisk /dev/sdb``

ورودی‌های تعاملی در محیط fdisk:

1. کلید n ⬅️ ایجاد پارتیشن جدید (New Partition)
2. کلید p ⬅️ انتخاب نوع پارتیشن اصلی (Primary)
3. کلید 1 ⬅️ شماره پارتیشن
4. کلید Enter ⬅️ تایید First Sector پیش‌فرض
5. عبارت +5G ⬅️ تعیین حجم پارتیشن (۵ گیگابایت)
6. کلید w ⬅️ ذخیره تغییرات و خروج (Write & Exit)

اطمینان از ساخت پارتیشن sdb1:

``lsblk``

### 3️⃣ ایجاد سیستم‌فایل (Create File System)

برای ساخت سیستم‌فایل ext4 روی پارتیشن جدید:

``sudo mkfs.ext4 /dev/sdb1``

### 4️⃣ ساخت مسیر و اتصال پارتیشن (Create Mount Point & Mount)

```
sudo mkdir -p /mnt/practice_disk
sudo mount /dev/sdb1 /mnt/practice_disk
```

تست و تایید صحت اتصال و مشاهده فضای پارتیشن:

``df -h /mnt/practice_disk``

### 🧹 پاکسازی و بازگردانی به حالت اولیه (Cleanup & Reset)

اگر می‌خواهید این تمرین را از ابتدا تکرار کنید، مراحل زیر را برای پاکسازی دیسک انجام دهید:

#### ۱. قطع اتصال پارتیشن (Unmount)

``sudo umount /dev/sdb1``

**(در صورت مواجهه با خطای target is busy از دستور ``sudo umount -l /dev/sdb1`` استفاده کنید).**

#### ۲. حذف پارتیشن‌ها

ورود مجدد به fdisk:

``sudo fdisk /dev/sdb``

1. کلید d ⬅️ حذف پارتیشن (Delete)
2. کلید w ⬅️ ذخیره و خروج

#### ۳. بررسی نهایی

``lsblk``
