## 🔄 سناریوی تکمیلی: ساخت و فعال‌سازی فضای Swap (Swap Partition Scenario)

حافظه Swap یا Swap Space، بخشی از دیسک سخت است که در صورت پر شدن حافظه رم (RAM)، سیستم‌عامل اطلاعات کم‌کاربرد رم را به آن منتقل می‌کند.

---

### 1️⃣ ساخت پارتیشن جدید برای Swap
ورود به ابزار مدیریت دیسک `sdb`:

```bash
sudo fdisk /dev/sdb
```

### ورودی‌های تعاملی در fdisk:

1. کلید n ⬅️ ایجاد پارتیشن جدید (New Partition)
2. کلید p ⬅️ انتخاب نوع پارتیشن اصلی (Primary)
3. کلید 2 ⬅️ شماره پارتیشن (مثلاً پارتیشن دوم)
4. کلید Enter ⬅️ تایید First Sector پیش‌فرض
5. عبارت +2G ⬅️ تعیین حجم پارتیشن Swap (مثلاً ۲ گیگابایت)
6. کلید t ⬅️ تغییر نوع پارتیشن (Change Partition Type)
7. ورود کد 82 یا عبارت swap ⬅️ تنظیم تایپ روی Linux swap
8. کلید w ⬅️ ذخیره تغییرات و خروج (Write & Exit)

### 2️⃣ آماده‌سازی و فرمت پارتیشن Swap

تبدیل پارتیشن ساخت‌شده (sdb2) به ساختار Swap:

```
sudo mkswap /dev/sdb2
```

### 3️⃣ فعال‌سازی فضای Swap

روشن و فعال کردن پارتیشن Swap در سیستم:

``sudo swapon /dev/sdb2``

تست و تایید فعال شدن فضای Swap:

``sudo swapon --show``

یا با دستور زیر مقدار رم و Swap فعال را مشاهده کنید:

``free -h``

### 4️⃣ غیرفعال‌سازی و پاکسازی Swap (Deactivation & Cleanup)

اگر خواستید فضای Swap ساخته‌شده را غیرفعال و پاک کنید:

```
# غیرفعال کردن فضای Swap
sudo swapoff /dev/sdb2

# بررسی غیرفعال شدن
free -h
```

پس از غیرفعال‌سازی، می‌توانید به راحتی پارتیشن sdb2 را مانند مراحل قبل با دستور ``sudo fdisk /dev/sdb`` و کلید ``d`` پاک کنید.
