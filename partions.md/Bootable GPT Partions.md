## ساخت پارتیشن بوت (Bootable) روی جدول پارتیشن GPT

در سیستم‌های جدید که از **UEFI** پشتیبانی می‌کنند، جدول پارتیشن **GPT** جایگزین MBR شده است. برای اینکه یک دیسک GPT قابلیت بوت (Bootable) داشته باشد، نیازمند یک پارتیشن خاص به نام **ESP (EFI System Partition)** با سیستم‌فایل **FAT32** هستیم.

---

### 📌 پیش‌نیازها
- دیسک خام (در این سناریو `/dev/sdb`)
- سیستم‌عامل با پشتیبانی از UEFI

---

### 1️⃣ ایجاد جدول پارتیشن GPT و پارتیشن EFI
وارد ابزار `fdisk` برای مدیریت دیسک `sdb` شوید:

```bash
sudo fdisk /dev/sdb
```

### ورودی‌های تعاملی در fdisk:

1. کلید g ⬅️ ایجاد یک جدول پارتیشن خام از نوع GPT (Create a new empty GPT partition table)
2. کلید n ⬅️ ایجاد پارتیشن جدید برای EFI
3. فشردن Enter ⬅️ انتخاب شماره پیش‌فرض (پارتیشن 1)
4. فشردن Enter ⬅️ تایید First Sector پیش‌فرض
5. عبارت +512M ⬅️ تعیین حجم پارتیشن بوت (معمولاً ۵۱۲ مگابایت کافی است)
6. کلید t ⬅️ تغییر نوع پارتیشن (Change Partition Type)
7. تایپ عبارت EFI System یا کد 1 ⬅️ تنظیم نوع پارتیشن روی EFI System
8. کلید w ⬅️ ذخیره تغییرات و خروج (Write & Exit)

### 2️⃣ ایجاد پارتیشن سیستم‌عامل (Root Partition)

برای اضافه کردن پارتیشن اصلی سیستم‌عامل در کنار پارتیشن EFI:

``sudo fdisk /dev/sdb``

1. کلید n ⬅️ پارتیشن جدید
2. فشردن Enter برای شماره پارتیشن 2 و First Sector پیش‌فرض
3. تعیین حجم (مثلاً +15G یا فشردن Enter برای تخصیص بقیه فضا)
4. کلید w ⬅️ ذخیره و خروج

### 3️⃣ فرمت کردن پارتیشن‌ها (Formatting)

**الف) فرمت پارتیشن EFI:**

پارتیشن EFI طبق استاندارد UEFI حتماً باید با سیستم‌فایل FAT32 فرمت شود:

``sudo mkfs.vfat -F32 /dev/sdb1``

**ب) فرمت پارتیشن اصلی سیستم‌عامل (Root):**

``sudo mkfs.ext4 /dev/sdb2``

### 4️⃣ ساخت مسیرها و متصل کردن پارتیشن‌ها (Mounting)

برای شبیه‌سازی ساختار نصب سیستم‌عامل بوت‌پذیر:

```
# ساخت دایرکتوری Root
sudo mkdir -p /mnt/boot_disk

# اتصال پارتیشن اصلی
sudo mount /dev/sdb2 /mnt/boot_disk

# ساخت پوشه efi داخل سیستم‌عامل و اتصال پارتیشن EFI
sudo mkdir -p /mnt/boot_disk/boot/efi
sudo mount /dev/sdb1 /mnt/boot_disk/boot/efi
```

### 5️⃣ بررسی و اعتبارسنجی ساختار Bootable

جهت اطمینان از صحت نوع پارتیشن و سیستم‌فایل‌ها:

``lsblk -o NAME,SIZE,FSTYPE,TYPE,PARTTYPENAME /dev/sdb``

خروجی مورد انتظار:

* ا sdb1 دارای سیستم‌فایل vfat و نوع EFI System
* ا sdb2 دارای سیستم‌فایل ext4 و متصل به ``/mnt/boot_disk``
