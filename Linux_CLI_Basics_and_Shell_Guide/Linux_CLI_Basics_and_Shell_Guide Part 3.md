# 💻 راهنمای جامع و کاربردی: مباحث کاربردی خط فرمان لینوکس (پارت سوم)

این داکیومنت بخش سوم از سری مستندات آموزش خط فرمان لینوکس است. در این سند به بررسی مدیریت فایل‌ها و دایرکتوری‌ها، عملیات کپی/انتقال/حذف، هدایت ورودی و خروجی‌ها (Redirection & Pipes) و در نهایت کالبدشکافی انواع ابزارهای فشرده‌سازی در لینوکس پرداخته می‌شود.

### 📋 فهرست مطالب

1. نحوه مدیریت و ساختن فایل‌ها و دایرکتوری‌ها
2. کپی کردن، جابه‌جا کردن و حذف کردن فایل‌ها و دایرکتوری‌ها
3. هدایت خروجی و ورودی دستورات (Redirection & Pipes)
4. معرفی و آموزش انواع ابزارهای فشرده‌سازی

### 1️⃣ نحوه مدیریت و ساختن فایل‌ها و دایرکتوری‌ها

در لینوکس همه‌چیز حول فایل‌ها و دایرکتوری‌ها می‌چرخد. برای مدیریت صحیح، شناخت مسیرها و دستورات پایه الزامی است.

### 💡 مفاهیم مسیرها (Paths):

* مسیر مطلق (Absolute Path): مسیری که دقیقاً از ریشه (``/``) شروع می‌شود.
* مسیر نسبی (Relative Path): مسیری که نسبت به موقعیت فعلی سنجیده می‌شود (``.`` برای پوشه فعلی، ``..`` برای پوشه قبل).

### ۱. دستورات پیمایش و مشاهده

* ا ``pwd`` : نمایش مسیر دقیق پوشه‌ای که در آن هستید.
* ا ``cd <path>`` : جابه‌جایی بین پوشه‌ها.
* ا ``ls -lah`` : لیست کردن تمام فایل‌ها (حتی مخفی‌ها) با جزئیات کامل و حجم خوانا.

```
# رفتن به پوشه Home و مشاهده لیست فایل‌ها
cd ~
ls -lah
```

### ۲. ساخت دایرکتوری با ``mkdir``

```
# ساخت یک پوشه
mkdir my_project

# ساخت پوشه‌های تو در تو به صورت یکجا
mkdir -p project/src/components
```

### ۳. ساخت فایل با ``touch``

```
# ساخت فایل‌های خالی
touch index.html style.css app.js
```

### 2️⃣ کپی کردن، جابه‌جا کردن و حذف کردن فایل‌ها و دایرکتوری‌ها

### 💡 ۱. کپی کردن با cp

برای کپی کردن پوشه‌ها حتماً از سوئیچ ``-r`` (بازگشتی) استفاده می‌شود.

```
# کپی فایل
cp config.txt config_backup.txt

# کپی کامل یک پوشه
cp -r project/ project_backup/
```

### 💡 ۲. جابه‌جایی و تغییر نام با mv

دستور ``mv`` هم برای تغییر نام و هم برای انتقال به مسیر جدید استفاده می‌شود.

```
# تغییر نام فایل
mv old_name.txt new_name.txt

# انتقال فایل به پوشه دیگر
mv document.pdf ~/Documents/
```

### 💡 ۳. حذف کردن با ``rm``

نکته: در خط فرمان لینوکس سطل زباله وجود ندارد و فایل‌های حذف شده بازنمی‌گردند.

```
# حذف فایل
rm file.txt

# حذف پوشه و تمام محتویات آن
rm -rf old_project/
```

### 3️⃣ هدایت خروجی و ورودی دستورات (Redirection & Pipes)

یکی از قدرتمندترین ویژگی‌های لینوکس، اتصال خروجی یک دستور به ورودی دستور دیگر است.

### 💡 ۱. هدایت خروجی (Redirection)

* ا ``>`` : ذخیره خروجی در فایل (جایگزین کردن محتوا).
* ا ``>>`` : اضافه کردن خروجی به انتهای فایل (الحاق).
* ا ``2>`` : هدایت پیام‌های خطا به فایل.

```
# ذخیره خروجی ls در فایل
ls -la > files.txt

# اضافه کردن متن به انتهای فایل
echo "New Line" >> files.txt
```

### 💡 ۲. پیوند دستورات (Pipe ``|``)

کاراکتر ``|`` خروجی دستور سمت چپ را به ورودی دستور سمت راست می‌فرستد.

```
# جستجوی یک عبارت در خروجی دستور
ls /usr/bin | grep "python"

# شمارش تعداد خطوط خروجی
ls -1 | wc -l
```

### 4️⃣ معرفی و آموزش انواع ابزارهای فشرده‌سازی

در لینوکس آرشیو کردن (جمع‌آوری در یک فایل) با فشرده‌سازی (کاهش حجم) متفاوت است.

### 💡 ۱. ابزار ``tar`` (آرشیو و فشرده‌سازی)

رایج‌ترین ابزار در لینوکس که از الگوریتم‌های مختلف پشتیبانی می‌کند:

```
# ساخت فایل فشرده tar.gz (رایج و سریع)
tar -czvf archive.tar.gz folder/

# ساخت فایل فشرده tar.xz (حداکثر فشرده‌سازی)
tar -cJvf archive.tar.xz folder/

# استخراج (Extract) فایل فشرده
tar -xzvf archive.tar.gz -C /path/to/destination/
```

### 💡 ۲. فشرده‌سازی تک‌فایلی (``gzip``, ``xz``)

```
# فشرده‌سازی یک فایل
gzip large_file.txt

# خروج از فشرده‌سازی
gunzip large_file.txt.gz
```

### 💡 ۳. کار با ``zip`` و ``unzip``

```
# ساخت فایل zip
zip -r my_files.zip my_folder/

# استخراج فایل zip
unzip my_files.zip
```
