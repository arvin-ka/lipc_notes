این داکیومنت بخش چهارم از سری مستندات آموزش خط فرمان لینوکس است. در این سند به بررسی مفاهیم کاربردی شامل آرشیو و بکاپ‌گیری (``tar`` و ``cpio``)، سورت و پردازش فایل‌های متنی (``sort`` و ``sed``)، ابزارهای مشاهده فایل‌ها، جستجوی فایل‌ها و دایرکتوری‌ها (``find`` و ``fd``) و در نهایت جستجوی متن در درون فایل‌ها (``grep``) پرداخته می‌شود.

### 1️⃣ معرفی ابزار tar برای آرشیو کردن فایل‌ها

ابزار ``tar`` (مخفف Tape Archive) یکی از استانداردترین ابزارهای لینوکس برای بسته‌بندی چندین فایل و دایرکتوری در قالب یک فایل واحد (Archive) است.

### 💡 سوئیچ‌های کلیدی tar:

* ا ``-c`` : ساخت آرشیو جدید (Create)
* ا ``-x`` : استخراج آرشیو (Extract)
* ا ``-t`` : مشاهده لیست محتویات آرشیو (List)
* ا ``-v`` : نمایش جزئیات عملیات (Verbose)
* ا ``-f`` : تعیین نام فایل آرشیو (File - همیشه باید آخرین سوئیچ قبل نام فایل باشد)
* ا ``-z`` : فشرده‌سازی با ``gzip`` (``.tar.gz``)
* ا ``-j`` : فشرده‌سازی با ``bzip2`` (``.tar.bz2``)
* ا ``-J`` : فشرده‌سازی با ``xz`` (``.tar.xz``)

### ۱. ساخت آرشیو ساده و فشرده

```
# ساخت آرشیو ساده بدون فشرده‌سازی
tar -cvf backup.tar /path/to/docs

# ساخت آرشیو فشرده با gzip (پرکاربردترین حالت)
tar -czvf project.tar.gz project/

# ساخت آرشیو با فشرده‌سازی حداکثری xz
tar -cJvf logs.tar.xz /var/log/
```

### ۲. مشاهده و استخراج محتویات آرشیو

```
# مشاهده فایل‌های داخل آرشیو بدون استخراج
tar -tvf project.tar.gz

# استخراج آرشیو در پوشه فعلی
tar -xzvf project.tar.gz

# استخراج آرشیو در یک مسیر خاص
tar -xzvf project.tar.gz -C /opt/destination/
```

### 2️⃣ بکاپ‌گیری از فایل‌ها با ابزار cpio

ابزار ``cpio`` (Copy In and Out) یکی دیگر از ابزارهای قدیمی و فوق‌العاده انعطاف‌پذیر لینوکس برای بکاپ‌گیری است. این ابزار معمولاً ورودی خود را از لیست فایل‌های ورودی (مثلاً خروجی دستور ``find``) می‌گیرد.

### 💡 حالت‌های اصلی ``cpio``:

* ا ``-o`` یا ``--create`` : حالت Copy-Out (ساخت آرشیو)
* ا ``-i`` یا --extract : حالت Copy-In (استخراج آرشیو)
* ا ``-p`` : حالت Pass-through (کپی مستقیم ساختار پوشه‌ها به یک مسیر دیگر)
* ا ``-v`` : نمایش جزئیات
* ا ``-d`` : ساخت دایرکتوری‌ها در صورت نیاز هنگام استخراج
* ا ``-H format`` : تعیین فرمت آرشیو (مانند ``crc``, ``cpio``, ``tar``)
