# 💻 راهنمای جامع و کاربردی: دستورات و ابزارهای پرکاربرد خط فرمان لینوکس (پارت چهارم)

این داکیومنت بخش چهارم از سری مستندات آموزش خط فرمان لینوکس است. در این سند به بررسی مفاهیم کاربردی شامل آرشیو و بکاپ‌گیری (``tar`` و ``cpio``)، سورت و پردازش فایل‌های متنی (``sort`` و ``sed``)، ابزارهای مشاهده فایل‌ها، جستجوی فایل‌ها و دایرکتوری‌ها (``find`` و ``fd``) و در نهایت جستجوی متن در درون فایل‌ها (``grep``) پرداخته می‌شود.

### 📋 فهرست مطالب

1. معرفی ابزار tar برای آرشیو کردن فایل‌ها
2. بکاپ‌گیری از فایل‌ها با ابزار cpio
3. مرتب‌سازی (sort) محتوای فایل‌های متنی

### 1️⃣ معرفی ابزار tar برای آرشیو کردن فایل‌ها

ابزار ``tar`` (مخفف Tape Archive) یکی از استانداردترین ابزارهای لینوکس برای بسته‌بندی چندین فایل و دایرکتوری در قالب یک فایل واحد (Archive) است.

### 💡 سوئیچ‌های کلیدی tar:

* ا ``-c`` : ساخت آرشیو جدید (Create)
* ا ``-x`` : استخراج آرشیو (Extract)
* ا ``-t`` : مشاهده لیست محتویات آرشیو (List)
* ا ``-v`` : نمایش جزئیات عملیات (Verbose)
* ا ``-f`` : تعیین نام فایل آرشیو (File - همیشه باید آخرین سوئیچ قبل نام فایل باشد)
* ا ``-z`` : فشرده‌سازی با ``gzip`` (``.tar.gz``)
* ا ``-j`` : فشرده‌سازی با ``bzip2`` (``.tar.bz2``)
* ا ``-J`` : فشرده‌سازی با ``xz`` (``.tar.xz``)

### ۱. ساخت آرشیو ساده و فشرده

```
# ساخت آرشیو ساده بدون فشرده‌سازی
tar -cvf backup.tar /path/to/docs

# ساخت آرشیو فشرده با gzip (پرکاربردترین حالت)
tar -czvf project.tar.gz project/

# ساخت آرشیو با فشرده‌سازی حداکثری xz
tar -cJvf logs.tar.xz /var/log/
```

### ۲. مشاهده و استخراج محتویات آرشیو

```
# مشاهده فایل‌های داخل آرشیو بدون استخراج
tar -tvf project.tar.gz

# استخراج آرشیو در پوشه فعلی
tar -xzvf project.tar.gz

# استخراج آرشیو در یک مسیر خاص
tar -xzvf project.tar.gz -C /opt/destination/
```

### 2️⃣ بکاپ‌گیری از فایل‌ها با ابزار cpio

ابزار ``cpio`` (Copy In and Out) یکی دیگر از ابزارهای قدیمی و فوق‌العاده انعطاف‌پذیر لینوکس برای بکاپ‌گیری است. این ابزار معمولاً ورودی خود را از لیست فایل‌های ورودی (مثلاً خروجی دستور ``find``) می‌گیرد.

### 💡 حالت‌های اصلی ``cpio``:

* ا ``-o`` یا ``--create`` : حالت Copy-Out (ساخت آرشیو)
* ا ``-i`` یا --extract : حالت Copy-In (استخراج آرشیو)
* ا ``-p`` : حالت Pass-through (کپی مستقیم ساختار پوشه‌ها به یک مسیر دیگر)
* ا ``-v`` : نمایش جزئیات
* ا ``-d`` : ساخت دایرکتوری‌ها در صورت نیاز هنگام استخراج
* ا ``-H format`` : تعیین فرمت آرشیو (مانند ``crc``, ``cpio``, ``tar``)

### ۱. ساخت بکاپ از فایل‌ها

```
# بکاپ‌گیری از تمام فایل‌های txt. با ترکیب find و cpio
find . -name "*.txt" | cpio -ov > txt_backup.cpio

# بکاپ‌گیری از کل یک پوشه با فرمت crc
find /home/user/docs | cpio -o -H crc > docs_backup.cpio
```

### ۲. مشاهده و استخراج بکاپ

```
# مشاهده لیست فایل‌های داخل آرشیو cpio
cpio -it < txt_backup.cpio

# استخراج تمام فایل‌ها و ساخت پوشه‌های مربوطه
cpio -idv < txt_backup.cpio
```

### 3️⃣ مرتب‌سازی (sort) محتوای فایل‌های متنی

دستور ``sort`` برای مرتب‌سازی سطرهای یک فایل متنی بر اساس الفبا، عدد، ستون مشخص و یا معکوس کردن ترتیب استفاده می‌شود.

### 💡 سوئیچ‌های پرکاربرد:

* ا ``-n`` : مرتب‌سازی عددی (Numeric Sort)
* ا ``-r`` : مرتب‌سازی معکوس (Reverse)
* ا ``-u`` : حذف خطوط تکراری (Unique)
* ا ``-k`` : مرتب‌سازی بر اساس یک ستون خاص (Column Index)
* ا ``-t`` : تعیین کاراکتر جداکننده ستون‌ها (Delimiter)

مثال‌ها:

```
# مرتب‌سازی الفبایی ساده و نمایش در ترمینال
sort names.txt

# مرتب‌سازی عددی و ذخیره خروجی در فایل جدید
sort -n numbers.txt > sorted_numbers.txt

# مرتب‌سازی معکوس عددی
sort -nr scores.txt

# مرتب‌سازی بر اساس ستون دوم با جداکننده کاما (CSV)
sort -t',' -k2 -n data.csv

# مرتب‌سازی و حذف سطر‌های تکراری
sort -u list.txt
```

### 4️⃣ جایگزین کردن (Replace) کلمات در فایل‌های متنی با ``sed``

ابزار sed (Stream Editor) یکی از قدرتمندترین ابزارهای پردازش متن در لینوکس است که به شما امکان می‌دهد کلماتی را درون فایل متنی جستجو و جایگزین کنید.

### 💡 ساختار دستور جایگزینی: ``sed 's/old_word/new_word/g' filename``

* ا ``s`` : نشان‌دهنده دستور Substitute (جایگزینی)
* ا ``g`` : نشان‌دهنده Global (اعمال روی تمام تکرارهای آن خط، نه فقط اولی)
* ا ``-i`` : اعمال تغییرات مستقیماً روی خود فایل اصلی (In-place)

مثال‌ها:

```
# جایگزین کردن کلمه localhost با 127.0.0.1 و نمایش در خروجی
sed 's/localhost/127.0.0.1/g' config.conf

# اعمال تغییرات مستقیماً روی خود فایل config.conf
sed -i 's/localhost/127.0.0.1/g' config.conf

# جایگزین کردن بدون حساسیت به حروف بزرگ و کوچک (I)
sed 's/error/warning/gi' app.log

# ایجاد بکاپ از فایل اصلی قبل از اعمال تغییرات
sed -i.bak 's/v1.0/v2.0/g' version.txt
```

### 5️⃣ ابزارهای نمایش‌دهنده فایل‌های متنی

در لینوکس ابزارهای مختلفی برای خواندن فایل‌های متنی وجود دارد که هرکدام برای سناریوی خاصی مناسب هستند.

| دستور | کاربرد و ویژگی‌ها |
| :--- | :--- |
| ``cat`` | نمایش کامل محتوای فایل یکجا در ترمینال (مناسب برای فایل‌های کوچک). | 
| ``tac`` | نمایش محتوای فایل به صورت معکوس از خط آخر به خط اول. |
| ``less`` | مرور فایل‌های بزرگ به صورت صفحه‌به‌صفحه با قابلیت پیمایش و جستجو. |
| ``more`` | ابزار قدیمی‌تر مرور صفحه‌به‌صفحه (فقط امکان حرکت به سمت جلو دارد). |
| ``head`` | نمایش N خط اول فایل (پیش‌فرض ۱۰ خط). |
| ``tail`` | نمایش N خط آخر فایل (پیش‌فرض ۱۰ خط) + قابلیت پایش زنده لاگ‌ها. |

مثال‌ها:

```
# نمایش ۱۰ خط اول فایل
head -n 10 /var/log/syslog

# نمایش ۲۰ خط آخر فایل
tail -n 20 /var/log/syslog

# مشاهده زنده و لحظه‌ای تغییرات فایل لاگ (پایش زنده)
tail -f /var/log/nginx/access.log

# پیمایش تعاملی فایل‌های بزرگ با less (برای خروج کلید q را بزنید)
less /var/log/dpkg.log
```

### 6️⃣ چگونه در لینوکس به دنبال یک فایل یا دایرکتوری خاص بگردیم؟

برای پیدا کردن مکان فایل‌ها و پوشه‌ها در دیسک، دو ابزار کاربردی ``find`` (ابزار پیش‌فرض) و ``fd`` (ابزار مدرن و سریع‌تر) وجود دارند.

### 💡 ۱. استفاده از دستور ``find``

دستور ``find`` به صورت عمقی در دایرکتوری‌ها جستجو می‌کند.

### سوئیچ‌های مهم ``find``:

* ا ``-name`` : جستجو بر اساس نام (حساس به حروف بزرگ و کوچک)
* ا ``-iname`` : جستجو بر اساس نام (غیرحساس به حروف بزرگ و کوچک)
* ا ``-type`` : تعیین نوع (f برای فایل، d برای دایرکتوری)
* ا ``-size`` : جستجو بر اساس حجم فایل
* ا ``-mtime`` : جستجو بر اساس زمان آخرین تغییرات (روز)

```
# جستجوی فایلی به نام config.json در کل سیستم
find / -name "config.json"

# جستجوی فایل‌های با پسوند log. در پوشه var بدون حساسیت به حروف بزرگ/کوچک
find /var -iname "*.log"

# پیدا کردن فقط پوشه‌ها (دایرکتوری‌ها) با نام src
find . -type d -name "src"

# پیدا کردن فایل‌های بزرگتر از 100 مگابایت در پوشه Home
find ~ -type f -size +100M

# پیدا کردن فایل‌هایی که در ۲۴ ساعت گذشته تغییر کرده‌اند
find . -type f -mtime -1
```

### 💡 ۲. استفاده از دستور ``fd`` (مدرن و بسیار سریع)

اگر ابزار ``fd-find`` را نصب داشته باشید، جستجو بسیار سریع‌تر و با رنگ‌بندی خواناتر انجام می‌شود.

```
# جستجوی ساده فایل یا پوشه
fd config

# جستجو فقط برای فایل‌های python
fd -e py

# جستجو در یک مسیر خاص
fd error /var/log/
```

### 7️⃣ جستجوی کلمات در محتوای فایل‌های متنی لینوکس (grep)

دستور grep برای جستجوی یک رشته متنی یا عبارت باقاعده (Regex) در درون محتوای فایل‌ها استفاده می‌شود.

### 💡 سوئیچ‌های پرکاربرد grep:

* ا ``-i`` : صرف‌نظر از حروف بزرگ و کوچک (Case-insensitive)
* ا ``-r`` یا ``-R`` : جستجوی بازگشتی در تمام زیرپوشه‌ها (Recursive)
* ا ``-n`` : نمایش شماره خطی که کلمه در آن پیدا شده
* ا ``-v`` : معکوس کردن جستجو (نمایش خطوطی که شامل کلمه نیستند)
* ا ``-c`` : فقط شمارش تعداد خطوط یافت شده
* ا ``-w`` : جستجوی دقیق کلمه (Whole word)

مثال‌ها:

```
# جستجوی کلمه "ERROR" در یک فایل مشخص
grep "ERROR" app.log

# جستجوی کلمه "failed" بدون حساسیت به حروف بزرگ/کوچک همراه با شماره خط
grep -in "failed" auth.log

# جستجوی بازگشتی کلمه "DATABASE_URL" در تمام فایل‌های پروژه
grep -rn "DATABASE_URL" ./src/

# نمایش خطوطی که حاوی کلمه "DEBUG" نیستند
grep -v "DEBUG" server.log

# ترکیب grep با Pipe برای فیلتر کردن خروجی دستورات دیگر
ps aux | grep "nginx"
```
