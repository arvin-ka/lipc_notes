## 1️⃣ مفهوم Shell و ساختار دستورات در CLI

### 💡 شل (Shell) چیست؟
شل در واقع مترجم بین شما و هسته سیستم‌عامل (Kernel) است. وقتی در خط فرمان تایپ می‌کنید، شل دستور شما را می‌گیرد، آن را به زبان قابل فهم برای سیستم‌عامل تبدیل می‌کند و نتیجه را به شما نشان می‌دهد. 
* معروف‌ترین شل در لینوکس **Bash** (Bourne Again Shell) نام دارد.

### 📜 ساختار کلی یک دستور در لینوکس:
تمام دستورات لینوکس از یک فرمول کلی پیروی می‌کنند:

```text
Command [Options] [Arguments]
```

1. ا Command (دستور اصلی): کاری که می‌خواهید انجام دهید (مثل ``ls`` برای لیست کردن فایل‌ها).
2. ا Options (سوئیچ‌ها/گزینه‌ها): شیوه رفتار دستور را تغییر می‌دهند و معمولاً با ``-`` یا ``--`` شروع می‌شوند (مثل ``-l`` یا ``--help``).
3. ا Arguments (آرگومان‌ها): هدف یا سوژه دستور هستند؛ مانند نام یک فایل، پوشه یا آدرس (مثل ``/etc/passwd``).

### 💡 مثال‌های درک ساختار:

####  مثال ۱ (فقط دستور):

``pwd``

(بدون سوئیچ و آرگومان - آدرس پوشه فعلی را نشان می‌دهد).

#### مثال ۲ (دستور + آرگومان):

``cd /var/log``

(دستور ``cd`` به همراه آرگومان ``/var/log`` که مسیر مقصد است).

#### مثال ۳ (دستور + سوئیچ + آرگومان):

``ls -l /home``

(دستور ls با سوئیچ ``-l`` برای نمایش جزئیات و آرگومان ``/home`` برای مشخص کردن پوشه).

### 2️⃣ دستورات ابتدایی و پرکاربرد محیط CLI

در این بخش مهم‌ترین دستورات پایه که هر روز با آن‌ها سروکار دارید آورده شده است.

### 🔹 ۱. دستور pwd`` (Print Working Directory)``

نشان می‌دهد دقیقاً در چه مسافتی از سیستم‌عامل قرار دارید.

``pwd``

خروجی نمونه: ``/home/arvin``

### 🔹 ۲. دستور ls`` (List)``

محتویات یک پوشه را نمایش می‌دهد.

#### مثال‌ها:

```
# لیست کردن ساده محتویات پوشه فعلی
ls

# نمایش تمام فایل‌ها از جمله فایل‌های مخفی (که با . شروع می‌شوند)
ls -a

# نمایش لیست با جزئیات کامل (حجم، دسترسی‌ها، مالک، تاریخ)
ls -l

# ترکیب سوئیچ‌ها: نمایش فایل‌های مخفی با جزئیات کامل و حجم‌های خوانا (Human-readable)
ls -lah
```

### 🔹 ۳. دستور cd`` (Change Directory)``

برای جابه‌جا شدن بین پوشه‌ها استفاده می‌شود.

#### مثال‌ها:

```
# رفتن به یک پوشه مشخص
cd /var/www

# یک پوشه به عقب برگشتن (Parent Directory)
cd ..

# دو پوشه به عقب برگشتن
cd ../..

# برگشتن مستقیماً به پوشه خانگی (Home Directory) کاربر
cd ~
# یا فقط
cd

# بازگشت به آخرین پوشه‌ای که قبل از این در آن بودید
cd -
```

### 🔹 ۴. ساخت و حذف پوشه (``mkdir`` & ``rmdir``)

### #### مثال‌ها:

```
# ساخت یک پوشه به نام project
mkdir project

# ساخت پوشه‌های تو در تو به صورت یکجا
mkdir -p project/2026/documents

# حذف یک پوشه خالی
rmdir project
```

### 🔹 ۵. ساخت، کپی، جابه‌جایی و حذف فایل‌ها (``touch``, ``cp``, ``mv``, ``rm``)

#### ایجاد فایل خالی:

``touch notes.txt``

#### کپی کردن (Copy):

```
# کپی یک فایل به نام جدید
cp notes.txt notes_backup.txt

# کپی کامل یک پوشه با تمام محتویات آن
cp -r project/ project_backup/
```

#### انتقال یا تغییر نام (Move / Rename):

```
# تغییر نام فایل
mv notes.txt important.txt

# انتقال فایل به پوشه‌ای دیگر
mv important.txt /tmp/
```

#### حذف کردن (Remove):

```
# حذف یک فایل معمولی
rm important.txt

# حذف یک پوشه و تمام محتویات داخل آن (با احتیاط استفاده شود!)
rm -rf project/
```

### 🔹 ۶. مشاهده محتوای فایل‌ها (``cat``, ``less``, ``head``, ``tail``)

#### نمایش کامل متن فایل:

``cat /etc/issue``

#### خوانش فایل‌های طولانی با امکان پیمایش (با کلید q خارج شوید):

``less /var/log/syslog``

#### نمایش ۱۰ سطر اول فایل:

``head -n 10 /etc/passwd``

#### نمایش ۱۰ سطر آخر فایل (کاربردی برای لاگ‌ها):

```
tail -n 10 /var/log/syslog

# مشاهده زنده و لحظه‌ای تغییرات لاگ
tail -f /var/log/syslog
```

### 3️⃣ مدیریت و جابه‌جایی بین کاربران (User Management)

در لینوکس دو نوع کاربر اصلی داریم:

1. کاربر عادی: دسترسی محدود به سیستم دارد و نمی‌تواند فایل‌های مهم سیستم‌عامل را دستکاری کند.
2. کاربر ریشه (root): مدیر کل سیستم با دسترسی بی‌نهایت.

### 🔹 ۱. دستور ``whoami`` و ``id``

نشان می‌دهند هم‌اکنون با چه کاربری وارد شده‌اید و چه شناسه/گروه‌هایی دارید.

```
# خروجی نمونه: uid=1000(arvin) gid=1000(arvin) groups=1000(arvin),27(sudo)...

```

### 🔹 ۲. دستور su`` (Switch User)``

برای سوئیچ کردن و تبدیل شدن به یک کاربر دیگر استفاده می‌شود.

```
# تغییر کاربر به root (نیاز به رمز عبور root دارد)
su -

# تغییر کاربر به یک کاربر مشخص در سیستم (مثلاً ali)
su - ali
```

نکته: علامت ``-`` باعث می‌شود تمام متغیرهای محیطی و پوشه خانگی کاربر جدید به‌طور کامل بارگذاری شود (توصیه می‌شود همیشه استفاده کنید).

### 🔹 ۳. دستور sudo`` (SuperUser DO)``

اجرای یک دستور خاص با دسترسی دسترسی مدیر (root) بدون نیاز به سوئیچ کامل به کاربر root.

```
# بروزرسانی لیست پکیج‌ها (نیاز به sudo دارد)
sudo apt update

# ری‌استارت یک سرویس
sudo systemctl restart nginx
```

### 🔹 ۴. خروج از حساب کاربر فعلی (``exit`` / ``logout``)

وقتی با ``su`` یا ``sudo`` وارد مد دیگری شده‌اید، برای برگشت به کاربر قبلی یا بستن شل:

``exit``

### 4️⃣ فیلتر کردن و جستجوی فایل‌ها با کاراکترهای ویژه (Wildcards)

یکی از قدرت‌های اصلی خط فرمان، فیلتر کردن فایل‌ها با استفاده از کاراکترهای Wildcard (Globs) است. این کار باعث می‌شود به جای تایپ تک‌تک فایل‌ها، گروه‌هایی از فایل‌ها را یکجا انتخاب کنید.

### 💡 جدول کاراکترهای ویژه:

| کاراکتر | معنی و مفهوم |
| :--- | :--- |
``*`` | جایگزین **صفر یا چند** کاراکتر از هر نوع |
| ``?`` | جایگزین **دقیقاً یک** کاراکتر از هر نوع |
| ``[...]`` | جایگزین **یکی از کاراکترهای** داخل کروشه |
| ``[!...]`` | **به جز** کاراکترهای داخل کروشه |

### 🔹 ۱. استفاده از کاراکتر * (ستاره)

همه چیز را با الگوی مشخص شده تطبیق می‌دهد.

#### مثال ۱: نمایش تمام فایل‌هایی که پسوند ``.txt`` دارند:

``ls *.txt``

#### مثال ۲: لیست کردن تمام فایل‌هایی که با حرف ``doc`` شروع می‌شوند:

``ls doc*``

#### مثال ۳: کپی کردن تمام عکس‌های ``.jpg`` به یک پوشه دیگر:

``cp *.jpg /home/arvin/pictures/``

### 🔹 ۲. استفاده از کاراکتر ? (علامت سوال)

دقیقاً جایگزین یک کاراکتر می‌شود.

#### مثال ۱: یافتن فایل‌هایی مثل ``file1.txt`` یا ``fileA.txt`` (نام فایل ۴ حرفی + پسوند):

``ls file?.txt``

#### مثال ۲: لیست کردن فایل‌هایی که حرف دوم آن‌ها a است:

``ls ?a*``

#### 🔹 ۳. استفاده از کروشه ``[...]`` (مجموعه‌ها و بازه‌ها)

برای انتخاب کاراکترها از یک لیست یا بازه مشخص.

#### مثال ۱: یافتن فایل‌هایی که با ``file1`` یا ``file2`` یا ``file3`` شروع می‌شوند:

``ls file[123].txt``

#### مثال ۲: استفاده از بازه (Range): تمام فایل‌هایی که با اعداد ۱ تا ۵ شروع می‌شوند:

``ls file[1-5].txt``

#### مثال ۳: تمام فایل‌هایی که با یک حرف بزرگ انگلیسی شروع می‌شوند:

``ls [A-Z]*``

#### مثال ۴ (استثنا / نفی): تمام فایل‌هایی که نام آن‌ها با عدد شروع نمی‌شود:

``ls [!0-9]*``

### 🎯 جمع‌بندی

کار با خط فرمان لینوکس در ابتدا ممکن است عجیب به نظر برسد، اما ساختار منطقی و یکپارچه‌ای دارد. با یادگیری ساختار دستورات (``Command -Options Arguments``)، تسلط بر دستورات پایه حرکت در فایل سیستم، درک سطح دسترسی کاربران با ``sudo`` و ``su`` و استفاده از Wildcardها برای سرعت بخشیدن به کارها، می‌توانید به راحتی کنترل سیستم‌عامل لینوکس را در دست بگیرید.
