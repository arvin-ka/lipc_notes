## مقدمه: پروتکل‌های SFTP و SCP چیستند و چه تفاوتی با FTP دارند؟

در سیستم‌عامل‌های لینوکس و شبکه‌های کامپیوتر، انتقال فایل بین کلاینت و سرور یکی از متداول‌ترین وظایف مدیریت سیستم است. برای این کار پروتکل‌های متعددی وجود دارد، اما تفاوت‌های بنیادی در میزان امنیت و نحوه عملکرد آن‌ها وجود دارد:

* **FTP (File Transfer Protocol):** یکی از قدیمی‌ترین پروتکل‌های انتقال فایل است. **بزرگ‌ترین مشکل FTP عدم امنیت آن است**؛ زیرا داده‌ها، نام‌های کاربری و کلمات عبور به صورت متن ساده (Plaintext) منتقل می‌شوند و هر فردی در مسیر شبکه می‌تواند آن‌ها را شنود کند.
* **FTPS (FTP over SSL/TLS):** همان FTP است که یک لایه رمزنگاری SSL/TLS به آن اضافه شده است.
* **SCP (Secure Copy Protocol):** یک پروتکل قدیمی‌تر و بسیار سریع بر پایه **SSH** است که برای انتقال فایل‌ها و پوشه‌ها بین دو سیستم در شبکه استفاده می‌شود.
* **SFTP (SSH File Transfer Protocol):** یک پروتکل کاملاً مجزا (و غیرمرتبط با FTP) است که روی بستر **SSH** عمل می‌کند. SFTP علاوه بر انتقال فایل، امکانات کامل مدیریت فایل روی سرور (مانند ایجاد دایرکتوری، تغییر مجوزها، حذف فایل‌ها و پیمایش مسیرها) را فراهم می‌آورد.

### جدول مقایسه SFTP و SCP و FTP:

| ویژگی | FTP | SCP | SFTP |
| :--- | :--- | :--- | :--- |
| **بستر انتقال** | پروتکل اختصاصی FTP | بستر SSH (Port 22) | بستر SSH (Port 22) |
| **رمزنگاری** | ندارد (Plaintext) | دارد (SSH Encrypted) | دارد (SSH Encrypted) |
| **مدیریت فایل** | کامل | محدود به کپی | کامل (حذف، تغییر نام، پیمایش و...) |
| **قابلیت Resume** | بله | خیر (قطع اتصال یعنی شروع مجدد) | بله (ادامه دانلود/آپلود قطعی) |
| **سرعت** | بالا (بدون Overhead رمزنگاری) | بسیار بالا (مناسب فایل‌های حجیم) | مناسب و ایمن |

## ۱. پیش‌نیازها و نحوه کارکرد SFTP و SCP

از آن‌جا که هر دو پروتکل **SFTP** و **SCP** از زیرساخت **OpenSSH** استفاده می‌کنند، نیاز به نصب یک daemon جدید روی سرور ندارید. اگر سرویس `openssh-server` روی سرور شما نصب و فعال باشد، قابلیت‌های SFTP و SCP نیز به طور پیش‌فرض در دسترس خواهند بود.

### ساختار پورت و معماری

* **پورت پیش‌فرض:** پورت شماره **22 TCP** (مگر اینکه پورت SSH سرور تغییر کرده باشد).
* **معماری:** Client-Server. کلاینت درخواست اتصال را ارسال کرده، هویت‌سنجی انجام می‌شود و داده‌ها داخل یک کانال رمزنگاری‌شده عبور می‌کنند.

```
+------------------+                              +-------------------+
|  Client Machine  |                              |   Linux Server    |
|                  | ===== SSH Encrypted Tunnel =|                   |
|  (SFTP/SCP CLI)  |        (Port 22 TCP)         | (OpenSSH Daemon)  |
+------------------+                              +-------------------+
```

## ۲. آموزش جامع و کاربردی ابزار SCP (Secure Copy)

ابزار `scp` برای کپی سریع فایل‌ها بین کلاینت و سرور یا بین دو سرور مجزا استفاده می‌شود. نحوه سینتکس (Syntax) آن بسیار شبیه به دستور `cp` در لینوکس است.

### ساختار کلی دستور SCP:

```
scp [options] [source] [destination]
```
